# Automotive Market Data Analysis

This project involves a comprehensive analysis of a vehicle dataset to identify trends in manufacturing popularity, consumer color preferences, and pricing structures based on ownership history.

## Project Overview

The analysis utilizes a dataset of 18 luxury and performance vehicles (including BMW, Audi, Mercedes, Lexus, and Tesla) to answer key market questions.

## Key Findings

### 1. Most Popular Car Manufacturer

* **Winner:** **BMW**
* **Insights:** With 7 entries in the dataset, BMW significantly outpaces competitors like Audi (2) and Lexus (3).

### 2. Top Manufacturing Country

* **Winner:** **Germany**
* **Insights:** German-made vehicles dominate the list with 11 total entries, followed by Japan with 3.

### 3. Color Popularity

* **Most Popular:** **White** (6 vehicles).
* **Least Popular:** **Yellow** (1 vehicle).




### 4. Pricing by Ownership

The analysis calculates the average price of vehicles based on how many previous owners they have had:

| Ownership | Average Price (USD) |
| --- | --- |
| **1st Owner** | $36,513.67 |
| **2nd Owner** | $30,718.00 |
| **3rd Owner** | $63,746.33 |
| **4th Owner** | $22,520.00 |




## Dataset Structure

The raw data includes the following attributes for each entry:

* **Vehicle Details:** Car Model, Year, Kilometers driven (KM).
* **Specifications:** Color, Transmission type.
* **Market Data:** Owner status, Price (USD), Manufacturer, and Country of origin.

## Tools Used

* **Microsoft Excel:** Used for data entry, pivot-style counting, and average price calculations.
